# jonathan-berezin.github.io

Interactive personal site / CV for **Jonathan Berezin**.

**Live site:** https://jonathan-berezin.github.io

## Features

- Clean, responsive single-page design (dark / light mode)
- **Role lenses** — click a focus (Data Migration, EDI/HL7/FHIR, Python Tools, System Integration, UI/UX, Mentoring) to highlight matching experience and fade the rest
- Expandable experience cards with tagged bullets
- Skills grouped by category
- Fully static — free on GitHub Pages, no build step

## Enabling GitHub Pages (one-time)

1. Go to the repository **Settings → Pages**
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Select branch **main** and folder **/ (root)**
4. Save

The site should appear at https://jonathan-berezin.github.io within a minute or two.

## Editing

Just edit `index.html` and push to `main`. The lenses, tags, and content are all in that one file for easy iteration.
